Set up secure driver data storage

This owner-only setup creates private driver profile, vehicle and document storage in Supabase. It never uploads documents. Driver-app users do not configure database credentials.

Use this only in the KAYAN project you created. The setup SQL contains database instructions, not passwords or secret keys.

Follow these steps

  1. Sign in to Supabase and open your KAYAN project.
  2. In the left menu, open SQL Editor, then click New query.
  3. For the first setup only, copy the private driver-data SQL, paste it into Supabase, and click Run. If you already ran it successfully, do not run it again.
  4. In Supabase, open Authentication → Sign In / Providers and enable Anonymous sign-ins and Phone. Phone OTP will not work until the maintainer deploys and configures the Yoola SMS hook.
  5. In Table Editor, confirm there are tables named driver_profiles, driver_vehicles, and driver_documents. In Storage, confirm driver-documents is private.

If Supabase shows an error: do not repeatedly run the query. Copy the error message (but not any keys or passwords) and send it to me so I can help safely.

After the initial database migration succeeds, the KAYAN app maintainer configures the project URL and public/publishable key in the app build settings. The Driver app itself never asks drivers to provide these values.

A demo account can be recovered with its verified phone only after Supabase Phone authentication and the Yoola SMS hook are configured and tested. Do not enter real driver details or upload real identity documents. This demo saves only fictional profile and vehicle data.
